# Udkast til ejer-godkendelse

Fast sted for tekster Claude drafter, som **kun ejeren** må poste/godkende (ejer-regel 3/8: "Gem generelt dine udkast, så jeg kan håndtere dem senere").

- Én fil pr. dato/emne: `<emne>-<YYYY-MM-DD>.md`
- Status øverst i hver fil: `AFVENTER EJER` / `POSTET <dato>` / `FORÆLDET`
- Discord-posts kræver ejerens ordrette ja (memory-regel 2/7) — Claude poster ALDRIG selv herfra.
- Når et udkast er håndteret: opdatér status-linjen (slet ikke filen — historik).
