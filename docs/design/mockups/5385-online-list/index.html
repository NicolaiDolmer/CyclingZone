Mockup only, no product code. Ejer-oenske 18/9 (#5385): clicking the "N online now" line should show who is online now and who was recently online, capped so the list never runs unbounded. Overlaps #4751's "clickable list of online managers -> page with all online managers" line item from the forum/social package; this mockup covers that one item so the owner can go on direction before either #5385 or the matching part of #4751 is built. All manager and team names below are invented for the mockup, never real players.

Privacy line: the brief asks to check whether a "show me as online" setting already exists. It does not - ProfilePage.jsx's Settings -> Privacy tab only has cookie-consent choices (necessary/analytics/marketing/email), no online-visibility toggle. The line is shown below marked FORSLAG - a proposal, not a shipped setting.
