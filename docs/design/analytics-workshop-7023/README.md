# Visuelle referencer fra brainstorm #7023

Dato 21/10/2026. Disse er selvstændige HTML-referencer, der kan åbnes i en browser på pc1. De er ikke implementering, produktionsscreenshots eller build-godkendelse. Navne og tal er opdigtede; evnerne i tabelskitsen er kun et illustrativt udvalg.

1. [Sum eller enkelte evner](udvikling-valg.html): ejer valgte B, begge dele.
2. [Periode](udvikling-periode.html): ejer valgte A, indeværende sæson.
3. [Desktop og mobil](trup-udvikling-desktop-mobil.html): interaktiv sortering, mobilkolonner og Fuld tabel. Ejer gav positiv skitsefeedback.

Lokale knapper ændrer alene eksemplet. De oprindelige chat-handlinger er fjernet fra de eksporterede referencer; valgene ovenfor er den vedtagne beslutningslog. Startvisningerne er bragt i overensstemmelse med ejerens valg. Referencerne indeholder ingen produktionsdata eller adgangsnøgler.

Senere historikundersøgelse fandt delvis datadækning. Tabelskitsens komplette eksempelsum er derfor ikke bevis for komplette sæsontal i produktion. [Designets beslutningskort](../../superpowers/specs/2026-10-21-7023-analytics-workshop-design.md#konkret-manglende-produktbeslutning-før-build) afklarer det før byg.
