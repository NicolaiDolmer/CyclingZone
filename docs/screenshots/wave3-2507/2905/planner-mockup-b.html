Model B in one sentence

The page opens on the assistant's finished plan. The list is the surface you edit, one native select per rider, and the board becomes a check-for-clashes view underneath.

What it changes versus today
  1. The primary action is a form control, not a gesture. It is discoverable, keyboard accessible and identical on mobile.
  2. "Start-line form" turns every row into a decision with a visible consequence.
  3. The race list and the board stop competing: the race picker lives inside the row, so there is one place to plan and one place to verify.
  4. The assistant's reasoning sits on the row it applies to, not in a page-level banner.
  5. Cost: the timeline stops being where you plan, so nuance like "move this peak two weeks earlier" needs the drawer rather than a drag.
