## Afvigelser/læringer

- **Session-crash midt i bølgen kostede intet**, fordi hvert spor pushede + oprettede PR selv (lane-pool-mønstret holder). Recovery = journal + `git worktree`-tilstand pr. lane, ikke antagelser.
- **CodeRabbit tæller hvert push som et review-forsøg.** Livstegn-pushes hvert 15. min på ikke-draft-PR'er åd hele kvoten. Nu: draft indtil klar (`make-wave-brief.mjs`), CLI-review i worktreet før `gh pr ready`.
- **En "fixture-fejl" var en motor-bug.** Regel bekræftet: undersøg rod-årsag før du rører fixtures; en vagt der kræver at events matcher næste snapshot fanger klassen fremover.
- **Fakta-agent før svarudkast** fandt to reelle fejl (#4987 støj-hash, puncheur-opskrift for bred) ud af fem spillerspørgsmål. Spillerspørgsmål er triage-input, ikke kun support.
- **Mock-login i browser-panelet virkede ikke** (klik registreredes ikke, screenshots timede ud); ejeren testede på Vercel-preview med egen konto i stedet. Ikke løst; notér hvis det gentager sig.
- **Stacked PR'er dør når basen merges med `--delete-branch`.** GitHub lukker PR'en automatisk og nægter genåbning efter force-push. Regel: `gh pr edit <N> --base main` på den stackede PR FØR basen merges (eller merge basen uden `--delete-branch` og slet bagefter). #4989 → #4995 kostede 20 min.
- Worker-agenter kan ikke modtage beskeder efter spawn (SendMessage ikke tilgængelig); en worker der stopper midt i preflight skal have en frisk recovery-agent i SAMME worktree.
