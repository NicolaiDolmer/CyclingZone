# #6295 — git probe cleanup

En fejl i første unlink afbrød tidligere hele finally-oprydningen. Regressionen fejlede på main-versionen; cleanup forsøger nu hver egen markør uafhængigt og udsteder aldrig proof efter cleanup-fejl.
