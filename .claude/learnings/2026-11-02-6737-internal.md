# #6737: bounded backend test arguments

- Cause: relative paths reduced argv size but did not bound it as the suite grew.
- Before: the real runner with a synthetic large suite reached native Windows
  `spawnSync` and returned `ENAMETOOLONG`; regression command exited 1.
- Fix: sequential batches bounded by the quoted UTF-16 command length, including
  executable, forwarded flags, separators and NUL. Reject an oversized single file.
- Preserve: economyEngine remains a separate `isolation=none` pass; remaining
  files use default isolation, run once, and stop on the first nonzero outcome.
  Spawn errors still throw; signal-only termination still produces exit 1.
- Tests cover native argument round trips, long executable paths, quoting,
  boundary sizes, discovery avoidance, flags and failure propagation.
- No player behavior, engine/testdata, feature flags or migrations changed.
  No patch note: internal test infrastructure only. Refs #6737 and #7495.
