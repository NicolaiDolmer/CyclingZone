# Train-now bonus continuation contract

The initiating caller is not a durable entitlement. An assistant may finish work
after a partial manager press, including after controls turn OFF. Persist the
choice on the first rider/date lock; never infer it from executed_by or re-read
current controls when consuming that choice. Existing locks fail closed.

Publish the initial lock/choice, frozen eligibility and instant receipt-CAS stamp in
one transaction for bonus riders, including riders with no reserved stage slots.
Stamping only when the later freeze finishes leaves an earlier lost-upsert-response
gap. The first press must use the publication RPC: a lost response then leaves fully
discoverable work, and an internal freeze failure rolls back its initial locks too.

A stale entitlement read must fail within the same transaction as absolute ability
writes. The receipt trigger validates the stored choice so rejection rolls back
the complete tick, while the original receipt snapshot CAS handles slot conflicts.
Local PGlite and native PG17 tests exercise rollback and concurrency; OFF behavior
is compared against the existing independent frozen engine digests.

No player copy or activation is included. Claude PR3 owns copy/help/patch notes,
and parent owns registry publication, full verification and independent review.
