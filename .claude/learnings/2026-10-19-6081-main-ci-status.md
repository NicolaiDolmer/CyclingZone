# #6081: main-CI blev kaldt rød uden et afsluttet fejlresultat

Dato: 2026-10-19. Scope: merge-køens CI-vent og batch-status.

## Årsag og bevis
Watch-exit var allerede erstattet med polling i #6593/#6861.
Resterende fejl: timeout gav stadig ROED, og batch-kalderen læste alle false-resultater som CI-fejl.
Regressionstest viste queued ved timeout og completed/cancelled som ROED før rettelsen.

## Rettelse
Kun completed/failure klassificeres som fejl. Pending/ulæselige observationer venter inden for eksisterende deadline.
Timeout, STALL og andre afslutninger uden success stopper sikkert; ukendt batch-resultat gemmes som null.

## Verifikation og afgrænsning
Tests bruger eksplicit fast tid, skriptede gh-svar og produktionsfunktioner uden merge/netværk.
Dækker queued, in_progress, API-udfald, success, failure, cancelled, timed_out, tom conclusion og batch-resultater.
Ingen spillerrettet ændring: patch notes og FEATURE_REGISTRY er ikke relevante. NOW/MASTERPLAN ejes af Claude.

Målt: 65/65 merge-køtests, 7/7 nye regressionstests og preflight exit 0. Uafhængigt slutreview uden yderligere fund.
