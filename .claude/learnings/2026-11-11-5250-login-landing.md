# #5250: login landing must be decided before paint

- Root cause: edge knew only cz_session, while React treated unknown auth as anonymous. Existing localStorage-only players could receive marketing HTML before React loaded.
- Owner approved direct dashboard, static neutral loading, FULL tests and preview gate on 11/11.
- Root-routing test reproduced marketing 200 with a real session cookie before the change.
- Fix: actual cookie signal, legacy pre-paint guard, explicit unknown-auth gate, guarded anonymous SSR hydration.
- Security boundary: external Vercel rewrites forward cookies by default; strip credentials for every external destination.
- Rollout: deleting legacy storage breaks old tabs; even an anonymous old tab may later log in. Continuous compatibility bridge remains until a separately verified retirement.
- Storage events invalidate and reread; never replay an event payload into canonical storage.
- Evidence: pr-screens/5250 (compiled baseline c4f394eb0 and changed build, same mocked pending refresh).
- Verification results are recorded in the PR; production rollout and 24h Sentry observation remain Claude/owner release work.
